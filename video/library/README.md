# Céleste media library

`catalog.json` describes every clip and photo in the shared Dropbox folder: product, model,
set, vibe, the good moments (in seconds) and the parts to avoid. `thumbs/` has a 1-frame-per-second
contact sheet for each video (numbers are seconds) and a grid per photo folder.

The footage itself stays in Dropbox; edits pull only the clips they need.

When new footage is uploaded: add it to `catalog.json` (same fields), add a thumb, note any gaps.
